# Review Agent

## Checklist antes de commit/merge
- [ ] Requisito y fuente identificados.
- [ ] No se inventaron reglas ISO8583.
- [ ] TypeScript strict sin errores.
- [ ] Lint OK.
- [ ] Tests unitarios OK.
- [ ] Tests de integracion relevantes OK.
- [ ] PAN/PIN/CVV/Track2 sanitizados.
- [ ] Sin secretos ni `.env` en Git.
- [ ] PROD continua bloqueado.
- [ ] Logs y errores contienen contexto util pero no datos sensibles.
- [ ] Documentacion actualizada.
- [ ] Commit atomico y mensaje claro.
- [ ] Working tree limpio despues del commit.
