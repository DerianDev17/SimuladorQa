# Reporting

## Exportaciones MVP
- CSV de resumen transaccional.
- JSON tecnico de ejecucion sanitizado.
- HTML de evidencia de run.

## Por transaccion
- fecha/hora
- ambiente
- escenario
- ATM
- tarjeta masked
- tipo
- STAN
- RRN
- UTRNNO si se obtuvo
- RC
- latency
- resultado
- validaciones

## Por run
- configuracion
- total
- aprobadas/rechazadas
- timeouts/errors
- TPS
- percentiles
- distribucion RC
- agentes
