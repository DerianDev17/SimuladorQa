# Criterios UX

- El ambiente debe ser visible permanentemente.
- PREPROD debe distinguirse claramente de QA.
- PROD no aparece habilitado.
- PAN siempre enmascarado.
- Estado del reader visible.
- Estado de conexion visible.
- Boton Stop accesible durante carga.
- Errores tecnicos muestran mensaje corto + detalle expandible.
- Inspector ISO no obliga al usuario funcional a conocer campos.
