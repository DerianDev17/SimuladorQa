# Criterios UX

- El ambiente debe ser visible permanentemente.
- PREPROD debe distinguirse claramente de QA.
- PROD no aparece habilitado.
- PAN siempre enmascarado.
- Estado del reader visible.
- Estado de conexion visible.
- Boton Stop accesible durante carga.
- Errores tecnicos muestran mensaje corto + detalle expandible.
- Inspector ISO no obliga al usuario funcional a conocer campos.
- Tarjetas permite leer y guardar sin saltar entre paneles; el alias sugerido
  debe persistirse sin editarlo y recuperarse al recargar.
- Datos técnicos del lector plegados, inventario visible y formulario sin
  desbordamiento horizontal en ventanas de 1024 px.
- Alias inválido, retiro de tarjeta y fallo o timeout del guardado tienen
  estados visibles; nunca se presenta un guardado fallido como exitoso.
